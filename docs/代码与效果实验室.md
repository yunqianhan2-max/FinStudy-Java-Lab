# 代码与效果实验室

## 在手机上如何使用

1. 首页点击“代码与效果实验室”。
2. 下拉选择一个代码示例，例如“Button：点击后修改文字”。
3. 先看 XML：它定义一个 TextView 和一个 Button。再切到 Java：监听器中通过 setText 修改文字。
4. 点击“运行这段示例”。页面会滚动到运行效果区域，并显示真实按钮和文字。
5. 点击预览中的“开始学习”，观察文字从“等待按钮点击”变为“欢迎学习 Android！”。
6. 回看 Java，找到 onClick 中的 setText；点击“重新运行”恢复初始状态，再试一次。

代码区域可上下滚动，点击“展开完整代码”可以查看长代码、横向滚动和复制。切换示例会清空旧预览，新示例需要再次点击运行。

## 十个例子分别观察什么

TextView：运行后从 XML 默认文字变成 Java 设置的玫红色 24sp 文字。

LinearLayout：两个控件最初横排，点击预览按钮后切为竖排，再次点击切回。

Button：运行显示按钮，点击按钮触发 onClick 后才修改文字。

RadioGroup：两个选项互斥，监听器读取选中项。

CheckBox：多个选项可同时选中，取消某项后输出跟随变化。

SeekBar：0、50、100 分别对应 alpha 0、0.5、1；观察真实图片透明度。

RatingBar：五颗星，半星精度，评分变化时显示数值。

Spinner：三个字符串通过 ArrayAdapter 进入下拉框，选择后显示对应内容。

ListView：字符串数组成为纵向列表，点击条目显示名称。

GridView：六项内容排成三列两行，点击条目显示名称。

## 代码与效果怎样保持一致

每项有独立的 res/layout/demo_lab_*.xml 和 Demo*.java。界面展示 assets/lab 中的相同副本；自动测试逐字节核对。运行时加载 XML 并调用 Java bind 方法，预览中是真实原生控件。

这是面向课程固定示例的轻量运行演示。代码窗口只读，可复制；本版没有加入任意 Java 编辑、即时编译、项目创建或完整 Android Studio 模拟器功能。

## 怎样阅读实现

LabActivity：选择例子、读取代码、运行、重置和展开代码。

LabCatalog / LabExample：例子注册与描述信息。

LabExampleBinding：统一的 bind(View demoView) 方法。

DemoButton 等十个类：各自示例的真实 Java 逻辑，使用课件中的 findViewById 和匿名内部类监听器。

实验运行不记录测验成绩，也不修改收藏或知识掌握。它用于理解代码导致的界面和交互变化。
