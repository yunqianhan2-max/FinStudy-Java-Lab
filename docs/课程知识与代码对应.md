# 课程知识与代码对应

工程采用 Java + XML。以下区分实际运行的控件、页面技术和仅用于知识库讲解的内容，方便对照课件阅读和现场演示。

## 第一章 走进 Android

系统概念、历史、架构、应用领域、开发工具和跨平台边界，整理在 assets/knowledge.json 的 c1k1 至 c1k6；章节练习为 c1q01 至 c1q10。选择 Android 原生应用、Java 和 Android Studio 与课程技术路线一致。资料中的历史内容按课程范围整理，不据此宣称当前品牌市场份额或最新版系统情况。

## 第二章 第一个 Android 应用

Project/Module：settings.gradle 的 include ':app'。

清单文件：AndroidManifest.xml 声明十二个 Activity，MainActivity 配置 MAIN 与 LAUNCHER。BaseActivity 是公共父类，不是另一个独立界面。

Java 源码：app/src/main/java/com/finstudy/app。

资源目录：res/layout 保存各页面与列表项，res/drawable 保存矢量书本图标与卡片形状，res/values 保存颜色、样式与字符串。这里图标直接使用 drawable，不声称创建了 mipmap 文件夹。

资源访问：R.layout.activity_quiz、R.id.rg_answers、R.drawable.ic_book。android.R.layout.simple_spinner_item 是系统自带资源。

## 第三章 UI 设计基础

第 2–4 页 XML 与 Java 共同控制界面：每个 Activity 在 onCreate 中 setScreen（内部 setContentView），随后 findViewById 绑定 XML 控件。题目文本由 Java 设置，RadioButton/CheckBox 本身在 XML 声明。

第 7–10 页 LinearLayout：大部分页面按垂直方向组织，view_toolbar 使用横向排列；内容区 0dp 加 layout_weight=1 分配剩余高度，身份页脚不放进滚动区。

第 14–15 页 FrameLayout：activity_navigation 的 fragment_host 是 Fragment 容器。切换局部内容时外面的标题、输入框和身份页脚保持同一个 Activity。

第 21–22 页布局嵌套：通过 include 复用标题和身份；正文适当使用 ScrollView，ListView 页面直接分配剩余高度。

第 23–28 页 ConstraintLayout：首页 activity_main.xml 实际使用 androidx.constraintlayout.widget.ConstraintLayout。标题约束顶部、身份约束底部、滚动内容上下约束在两者之间，宽高 0dp 表示匹配约束。

第 31 页间距与对齐：padding 为内容留白，margin 分隔卡片，gravity 控制容器内的排列和文字对齐。

RelativeLayout、TableLayout、GridLayout 出现在课程知识和练习中，本版没有额外实现对应演示，不列为已经使用的页面布局。

## 第四章 常用 UI 组件

第 2–5 页 TextView/EditText：知识、成绩、固定身份；KnowledgeActivity 的搜索框和 TextWatcher。

第 6–8 页 Button/监听：MainActivity implements View.OnClickListener；DemoButton 使用 new View.OnClickListener。均为 Java，不是 Kotlin。

第 9 页 ImageButton：KnowledgeDetailActivity 的 ib_favorite，点击切换收藏与透明度。

第 11–12 页 RadioGroup/RadioButton：activity_quiz 的四个单选选项，以及 demo_lab_radio 的单选实验。每次只显示一题，组内互斥。

第 13–15 页 CheckBox：多选题、知识掌握标记、实验勾选和错题历史开关。

第 17–18 页 SeekBar：DemoSeek 的 OnSeekBarChangeListener，progress/100f 映射到 ImageView.setAlpha。浮点运算避免整数除法。

第 19–20 页 RatingBar：XML numStars=5、stepSize=0.5，Java 监听评分值。

第 21–22 页 ImageView：实验中显示书本矢量资源，scaleType=fitCenter。

第 24–28 页 Adapter：ChapterListActivity 用 SimpleAdapter 将 title、subtitle 映射到 item_chapter.xml；KnowledgeAdapter 继承 BaseAdapter，重写 getCount、getItem、getItemId、getView，并复用 convertView；Spinner 使用 ArrayAdapter。

第 31–34 页 Spinner：测验选章、错题筛选和控件实验；通过数组/集合加 ArrayAdapter 绑定。

第 35–39 页 ListView：章节、知识、收藏、错题与结果列表，使用 OnItemClickListener 处理选择。

第 40 页 Toast/Log：toast 显示提示；BaseActivity 用 Log.d 输出生命周期，Logcat 可筛选 FinStudyLifecycle。

GridView 在 2.1 版实际作为可运行代码示例使用：demo_lab_grid.xml 声明三列，DemoGrid 通过 ArrayAdapter 填充六个条目，并监听条目点击。

## 第五章 页面跳转

第 2–4 页生命周期：BaseActivity 重写七个回调并输出日志；首页、统计、知识列表在 onResume 刷新；NavigationActivity 显示最近事件。方法由 Android 系统调用，代码不手动调用其他 Activity 的 onCreate。

第 5 页创建、声明、启动与关闭：独立 Java Activity、XML 布局、清单声明、显式 Intent、finish。知识详情也成为独立 Activity。

第 6–8 页 Bundle 传值：章节列表传 chapter_id，收藏传 knowledge_id，错题传 question_id，结果页接收 attempt_id；跳转实验还传 message 字符串。发送和接收使用相同键与类型。

第 9–10 页返回结果：NavigationActivity 使用请求码 1001 打开 MessageActivity；子页 setResult(RESULT_OK, intent) 后 finish；父页 onActivityResult 检查请求码、结果码及 data。普通返回走取消分支。

第 11–16 页 Fragment：StudyFragment 重写 onCreateView，inflate fragment_study.xml；NavigationActivity 通过 setArguments 传入 kind，并使用 FragmentManager 的事务 replace/commit 切换学习步骤与自查清单。

平台 android.app.Fragment 和 startActivityForResult 是为贴合课程采用的旧式教学 API，并非现代项目推荐选型。Service、BroadcastReceiver、ContentProvider 仅作为四大组件知识介绍，没有把它们虚构成业务实现。

## 2.1 代码和效果对照

LabActivity 作为运行容器；十个 Demo*.java 类分别实现一个小例子。每项有独立 demo_lab_*.xml，assets/lab 保存逐字节相同的可阅读副本。运行按钮加载该 XML，再执行对应 bind 方法，所以展示的代码和交互效果可逐句对照。例子的选择、代码阅读、效果重置不修改知识掌握和测验记录。
